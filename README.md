# Resignation Line 0430

A one-line resignation letter written in the voice of a cron job that has run every minute since March, entered in the make.fun bounty [The Funniest One-Line Resignation Letter](https://make.fun/c/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947). The program `main.py` deterministically writes the single line to `/output/entry.txt`.
